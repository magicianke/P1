# Схема подключения

Пины задаются только в `src/board_config.h`. Если меняете их там, обновите и эту таблицу.

## Дисплей 3.5" IPS ILI9488 + тач (XPT2046) → ESP32-S3

| Пин модуля | ESP32-S3 | Примечание |
|---|---|---|
| VCC | 5V | Если на модуле нет стабилизатора 3,3 В — подавать 3V3. Проверить по плате |
| GND | GND | |
| CS | GPIO10 | |
| RESET | GPIO14 | |
| DC/RS | GPIO9 | |
| SDI (MOSI) | GPIO11 | |
| SCK | GPIO12 | |
| LED | GPIO21 | ШИМ подсветки. Проверить, что на модуле есть транзистор; иначе ток идёт напрямую через GPIO |
| SDO (MISO) | **не подключать** | ILI9488 не отпускает MISO и мешает тачу |
| T_CLK | GPIO12 | общий с SCK |
| T_CS | GPIO15 | |
| T_DIN | GPIO11 | общий с SDI |
| T_DO | GPIO13 | единственный источник на MISO |
| T_IRQ | GPIO16 | |

> Если на модуле вместо T_* пины CTP_SDA/CTP_SCL/CTP_INT/CTP_RST, тач **ёмкостный** (FT6236 / FT6336, I2C), и драйвер нужно менять.

## CAN-трансивер SN65HVD230DR (SOIC-8)

| Пин | Сигнал | Куда |
|---|---|---|
| 1 | D | GPIO5 (CAN TX) |
| 2 | GND | GND |
| 3 | VCC | 3V3 + конденсатор 100 нФ рядом с пином |
| 4 | R | GPIO4 (CAN RX) |
| 5 | Vref | не подключать |
| 6 | CANL | OBD-II pin 14 |
| 7 | CANH | OBD-II pin 6 |
| 8 | Rs | GND (режим high-speed) |

- **Терминатор 120 Ом не ставить**: шина в машине уже терминирована, устройство подключается отводом.
- Провода CANH/CANL — витой парой, отвод как можно короче.
- GND устройства соединить с OBD pin 4/5.

## Питание (в машине)
OBD pin 16 (+12 В постоянно) или провод ACC → предохранитель 1 А → защита от переполюсовки → TVS (SMBJ24A или аналог) → DC-DC 12→5 В (вход до 36–40 В) → пин 5V платы.
На столе плата питается от USB, внешние 5 В при этом не подключать.
