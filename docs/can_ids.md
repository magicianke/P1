# Журнал CAN ID — Subaru Impreza GH 2.0 / 4EAT TZ1

Сюда вносить **только** ID, проверенные снифером на этой машине.
Гипотезы из интернета — в отдельный раздел, с пометкой источника.

## Шина на OBD (pin 6/14)

Проверено 2026-10-14 (листен-онли, плата P1 rev 1.0 от USB): 500 кбит/с, 11-битные ID, ~895 кадров/с при включённом зажигании. При выключенном зажигании тишина.

| ID | Период, мс | Частота |
|---|---|---|
| 0x410, 0x411, 0x412, 0x420, 0x421, 0x422 | 10 | 100 Гц |
| 0x511, 0x512, 0x513, 0x514, 0x620 | 20 | 50 Гц |
| 0x501 | 40 | 25 Гц |
| 0x600 | 50 | 20 Гц |

Байты, которые меняются почти в каждом кадре на всех режимах, — скорее всего счётчики или контрольные суммы. На эти байты не смотреть как на сигналы: 0x421 B3, 0x422 B4, 0x501 B5, 0x512 B5, 0x514 B6, 0x600 B4. 0x411 B2 (3F–FF, 300 изменений за 30 с) — тоже служебный.

## Кандидаты (найдены снифером, нужна проверка)

Запись = метка лога из сессий 2026-10-14. Утро: `01_zazhiganie`, `02_holostoy`, `03_gaz`, `04_tormoz`, сравнение с `02_holostoy` (для `02` — с `01`). Вечер: `01_zazhiganie_2`, `07_dveri`, `02_holostoy_2`, `07_dveri_2`, `05_selector`, `06_rul`, сравнение с `02_holostoy_2` (для `07_dveri` — с `01_zazhiganie_2`).
